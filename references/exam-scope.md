# 命题范围

本文件列出工具的站点目录与题库所覆盖的考核范围，用于判断一道题落在哪个模块、该去哪个类别的来源取证。

**范围可能随赛区与年度变化，请以你所在赛区的官方说明为准。** 本文件是分类框架，不是官方命题文件的替代。

## 11 个模块

| 模块 | 内容 |
|---|---|
| **M1 文献信息基本概念** | 文献信息与信息素养基本概念；文献类型、标识符与 DOI；信息伦理；信息安全 |
| **M2 文献信息检索原理** | 检索语言；检索工具与检索途径；检索效率评价；检索类型（含 AI 增强检索、专业检索）；中国图书馆分类法 |
| **M3 信息检索理论与技术** | 检索语法；高级检索；布尔逻辑；截词检索；精确与模糊匹配；字段限制检索；结果筛选 |
| **M4 文献信息检索系统** | 网络指数；门户网站（行业/学会/协会）；学术搜索；馆藏查询系统；开放获取资源（含预印本） |
| **M5 常用中文商业数据库** | 中国知网；维普资讯；万方数据知识服务平台；考试类数据库；超星汇雅电子图书数据库 |
| **M6 政府开放信息资源** | 思政信息；开放数据；法律信息；标准及标准文献；专利及专利文献；商标及地理标志；反诈防骗；医卫信息；文教信息（含创业/升学）；证书资格信息 |
| **M7 实用学习资源** | 开放平台学习资源（含开放课程）；商业信息类查询资源（天眼查、企查查、爱企查等）；问答社区（知乎、简书、小红书） |
| **M8 学术写作** | 论文结构；写作辅助工具（PDF 处理、Office 插件、排版工具）；投稿流程与投稿系统；引用与参考文献著录格式；学术伦理（检索场景） |
| **M9 知识管理工具** | 文献管理工具（知网研学、NoteExpress、EndNote）；思维导图（XMind、MindMaster、FreeMind）；笔记软件（印象、为知、有道云）；问卷调查 |
| **M10 科研工具** | 数据处理工具；学术评价工具；可视化工具（文献与数据）；文献追踪工具 |
| **M11 AI 素养** | AI 基础知识与伦理规范；常用 AI 工具的认知与基本应用（含提示词工程）；常规应用场景（办公、科研、多模态、智能体，含图片搜索） |

## 按题目落到来源

拿到题后先判断它属于哪个模块，再去对应类别找来源。

| 题目在问什么 | 优先来源类别 | 目录中的入口示例 |
|---|---|---|
| 检索式怎么写、布尔逻辑、截词、字段限定 | 数据库自身的官方检索规则 | 维普官方检索规则、知网/万方高级检索说明页 |
| 某篇论文的题录、作者、刊期 | 官方 API 或记录页直达 | Crossref、DOI 解析、PubMed、arXiv |
| 引文数、被引量、排名 | 题目指定的那个工具或库 | OpenAlex、Semantic Scholar、Connected Papers、JCR 等 |
| 政府开放信息（法规、标准、专利、商标） | 主管机构的官方站点 | 国家法律法规数据库、国家标准全文公开系统、CNIPA 相关平台 |
| 商业信息（企业、诉讼、执行） | 官方公示系统优先，商业平台次之 | 国家企业信用信息公示系统、裁判文书网、执行信息公开网 |
| 学位论文、古籍、特藏 | 机构知识库或图书馆站点 | 各高校机构库、国家图书馆系列平台 |
| 工具功能、菜单、默认值 | 该产品当前版本的官方帮助 | 产品帮助中心，必要时看实际界面 |
| 数据文件内的人数、比例、极值 | 本地聚合，不联网 | 题目给定的文件 |
| 定义、概念、通用规则 | 稳定规则卡优先 | 见 [browser-automation.md](browser-automation.md) 的规则卡表 |

同一题落到多个模块时，按**选项**拆开证据缺口，共享同页资料，不重复检索已证实的部分。

## 站点目录

完整入口清单、别名、任务标签与每个入口的流程状态在：

- [search-index.json](search-index.json) —— 站点索引（入口、别名、任务类型、流程文件路径）
- [sources.json](sources.json) —— 基础来源目录
- [sites/](sites) —— 逐个站点的档案：入口、控件、流程、障碍记录

查某个站点前先读它的档案，不要凭印象操作。

## 使用目录时的边界

**目录覆盖不等于查询能力已验证。** 每个入口都有一份档案，状态分四类：

| 状态 | 含义 |
|---|---|
| `query_verified` | 代表性参数已实际提交，结果/空结果容器与详情路径已确认 |
| `entry_observed` | 观察到入口与当前控件，尚未实查完整查询 |
| `blocked` | 登录、验证码、机构权限或页面结构妨碍确认，档案里保存了实际障碍 |
| `disabled` | 有明确的停止服务或废弃依据。**连接失败不能单独推定停用** |

只有实际查过的定位器才能作为已确认控件；候选选择器、页面脚本里的字符串或旧版本页面都不能升级为当前确认。

**已有充分证据即答复**，不为了"走完流程"而额外开站，也不把目录当成固定预检名单。
